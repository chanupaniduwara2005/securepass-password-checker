📚 How Each Check Works

🔢 Length Check

Every extra character multiplies the number of combinations an attacker must try. A 12-character password has roughly trillions more combinations than an 8-character one. Minimum recommended length is 12 characters; aim for 16+.

🔠 Character Variety

Using uppercase, lowercase, digits, and symbols expands the "alphabet" an attacker must guess from. With only lowercase letters the alphabet is 26; adding all four types brings it to ~95. Larger alphabet = exponentially harder brute-force.

📋 Common Password Check

Attackers use dictionary attacks — lists of millions of known weak passwords like password123, qwerty, or iloveyou. If your password appears in such a list it can be cracked in seconds regardless of length.

🔁 Repeated Characters

Passwords like aaabbbccc or 111111 have very low entropy — they carry less unpredictable information than they appear to. Automated crackers detect and exploit this pattern immediately.

📈 Predictable Sequences

Sequences like 1234, abcd, or qwerty are keyboard walks or numerical runs — among the first things any cracker tries. They reduce your effective password strength dramatically.

🎲 Why crypto.getRandomValues()?

JavaScript's Math.random() is not cryptographically secure — its output can sometimes be predicted. crypto.getRandomValues() uses the operating system's secure random number generator, making it suitable for generating real passwords.
